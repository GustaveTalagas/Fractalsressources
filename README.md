# Générateur de Fractales (Mandelbrot)

Projet personnel combinant Python et Blender pour visualiser l'ensemble de Mandelbrot. 

## Le code
* `main.py`& `main2.py` & `constants.py` : Scripts Python gérant le calcul. `main.py` génère l'ensemble de Mandelbrot. `main2.py` génère les ensembles de Julia.
* Fichiers `.blend` : Fichiers de rendu 3D.
